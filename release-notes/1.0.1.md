## Inbox Curator v1.0.1

A language-handling improvement plus Obsidian API compatibility fixes.

### ✨ Highlights

- **`match-obsidian` output language** — A new prompt-language option that follows the Obsidian UI language, alongside auto-detect, force Japanese, force English, and match-note-language. Note-language detection was also improved.
- **Delete candidates respect your deletion preference** — Delete-candidate execution now uses `FileManager.trashFile()` so Obsidian's own deletion setting is honored.

### 🐛 Fixes

- Resolved Obsidian API compatibility and code-quality issues across the plugin.
- Improved popout-window compatibility.
- Tightened typing around provider requests, PDF extraction, and Base64 masking.
- Clarified intentional fire-and-forget logging calls with an explicit `void`.
- Added a repository social preview image.

**Requirements:** Obsidian `1.5.0`+ (desktop only)

### 🇯🇵 Inbox Curator v1.0.1

出力言語の改善と Obsidian API 互換性の修正を含むリリースです。

#### ✨ 主な変更

- **`match-obsidian` 出力言語** — Obsidian の UI 言語に追従するプロンプト言語オプションを追加しました（自動判定 / 日本語固定 / 英語固定 / ノート言語に合わせる、に加えて）。ノート言語の検出も改善しています。
- **削除候補が Obsidian の削除設定に従う** — 削除候補の実行に `FileManager.trashFile()` を使い、Obsidian の削除設定を尊重するようにしました。

#### 🐛 修正

- Obsidian API 互換性とコード品質の問題を修正しました。
- ポップアウトウィンドウ互換性を改善しました。
- プロバイダーリクエスト・PDF 抽出・Base64 マスク周辺の型を強化しました。
- 意図的な fire-and-forget ログ呼び出しに `void` を明示しました。
- リポジトリのソーシャルプレビュー画像を追加しました。

**動作要件:** Obsidian `1.5.0`+（デスクトップ専用）
