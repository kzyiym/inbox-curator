## Inbox Curator v1.1.0 — Safer, more controllable auto-sort

Auto-sort is now gated by an allowlist and per-action confidence thresholds, and you can review and approve every proposed action from one panel.

### ✨ Highlights

- **Action allowlist** — Per-action toggles (Archive, Read Later, Task, Delete Candidate) gate auto-execution and panel apply without changing review output.
- **Configurable confidence thresholds** — Set a minimum confidence per auto-sort action. Defaults preserve prior behavior: Medium for Archive/Read Later, High for Task.
- **Action review panel** — A unified dry-run preview / approval / execute-selected modal listing watched-folder notes with their proposed action, confidence, reliability, auto-execute verdict, and resolved destination. New commands: `Open action review panel` and `Dry-run auto-sort (preview)`.

### 🔒 Security

- Stop all auto-execution actions when prompt injection is detected. Image inputs, fetched external articles, and extracted PDF contents are also scanned or fail-closed.
- Enhanced concurrency safety: detect and abort if a note is modified during review, using hash comparison and atomic updates.
- Prevent SSRF: background polling/watch jobs cannot fetch remote URLs.
- Universal log masking redacts API keys, tokens, and Base64 payloads.
- Strengthened folder-path validation for AI-suggested destinations.

### 📝 Notes

- `ai_review_confidence` and `ai_review_reliability_label` are now persisted to note frontmatter so the panel can recompute decisions for already-reviewed notes.

**Requirements:** Obsidian `1.11.4`+ (desktop only)

### 🇯🇵 Inbox Curator v1.1.0 — より安全で制御しやすい自動仕分け

自動仕分けに許可リストとアクションごとの信頼度しきい値を導入し、提案アクションを1つのパネルで確認・承認できるようにしました。

#### ✨ 主な変更

- **アクション許可リスト** — Archive / Read Later / Task / Delete Candidate を個別にオン・オフでき、自動実行とパネル適用を制御します（レビュー出力は変わりません）。
- **信頼度しきい値の設定** — 自動仕分けアクションごとに最低信頼度を設定できます。既定値は従来の挙動を維持します（Archive / Read Later は Medium、Task は High）。
- **アクションレビューパネル** — ドライラン確認・承認・選択実行を1つにまとめたモーダルです。監視フォルダのノートについて、提案アクション・信頼度・信頼性・自動実行可否（と理由）・移動先を一覧表示します。新コマンド `Open action review panel` と `Dry-run auto-sort (preview)`。

#### 🔒 セキュリティ

- プロンプトインジェクションを検出すると、すべての自動実行アクションを停止します。画像入力・取得した外部記事・抽出した PDF 本文もスキャン対象、または fail-closed で扱います。
- 並行処理の安全性を強化：レビュー中にノートが変更された場合、ハッシュ比較とアトミック更新で検出して中止します。
- SSRF 対策：バックグラウンドのポーリング・監視ジョブはリモート URL を取得できません。
- ログのマスキングを徹底し、API キー・トークン・Base64 ペイロードを伏せます。
- AI が提案する移動先フォルダのパス検証を強化しました。

#### 📝 補足

- `ai_review_confidence` と `ai_review_reliability_label` をノートの frontmatter に保存するようにしました。これにより、レビュー済みノートの判定をパネルで再計算できます。

**動作要件:** Obsidian `1.11.4`+（デスクトップ専用）
