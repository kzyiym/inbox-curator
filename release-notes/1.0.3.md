## Inbox Curator v1.0.3

Addresses Obsidian plugin review feedback (Dashboard Phase 1).

### 🐛 Fixes

- Use Obsidian's `getLanguage()` API instead of `localStorage.getItem("language")`.
- Fix Promise-returned-where-void-expected in `onClick` handlers and add missing error handling.
- Add missing i18n keys for API-key deletion and log-clear failures.

### 🔒 Security

- Add GitHub artifact attestations to the release workflow for supply-chain transparency.

### 📝 Notes

- The API-key delete button keeps `setWarning()`. `setDestructive()` requires a newer minimum app version than `1.11.4`, so the earlier switch was reverted.

**Requirements:** Obsidian `1.11.4`+ (desktop only)

### 🇯🇵 Inbox Curator v1.0.3

Obsidian プラグインレビュー（Dashboard Phase 1）の指摘に対応したリリースです。

#### 🐛 修正

- `localStorage.getItem("language")` を Obsidian の `getLanguage()` API に置き換えました。
- `onClick` ハンドラの「void 期待箇所で Promise を返す」問題を修正し、不足していたエラーハンドリングを追加しました。
- API キー削除とログクリア失敗に関する i18n キーを追加しました。

#### 🔒 セキュリティ

- サプライチェーンの透明性のため、リリースワークフローに GitHub の成果物 attestation を追加しました。

#### 📝 補足

- API キー削除ボタンは `setWarning()` のままです。`setDestructive()` は最低アプリバージョン `1.11.4` より新しい Obsidian を必要とするため、一度の切り替えは元に戻されました。

**動作要件:** Obsidian `1.11.4`+（デスクトップ専用）
