## Inbox Curator v1.0.0 — Initial public release

Inbox Curator is an AI-powered Obsidian plugin that reviews, summarizes, and auto-sorts the notes in your inbox folder using OpenAI, Gemini, or Anthropic.

### ✨ Highlights

- **AI note review** — Structured verdicts (summary, credibility, tags, and a recommended action) from OpenAI-compatible, Gemini, and Anthropic endpoints.
- **Auto-sort with safety rails** — Archive, Read Later, and Task actions can be auto-executed; Delete Candidates are suggestions only and are moved to a quarantine folder, never deleted.
- **Batch processing** — Reviews run through an in-memory queue with configurable concurrency, rate limiting, and retry.
- **Rich input support** — URL article extraction, attachment awareness, multimodal image review (up to 3 images, 1 MB each), and experimental PDF text extraction.

### 📦 Also included

- Collection review: cross-note analysis for selected notes and folders.
- Auto-sort undo: `Undo last auto-sort run`.
- Content filtering with context budget presets (small / standard / large / custom).
- Structured operation logs (JSONL) and rotating error logs in `.inbox-curator/logs/`.
- Full English and Japanese UI (i18n).
- In-memory image optimization for source images up to 10 MB.
- Prompt injection detection with configurable blocking.
- Provider error classifier for clearer API error messages.
- Secure API key storage via Obsidian `SecretStorage` (in-memory session fallback).
- Deduplication via the `ai_review_source_hash` frontmatter field.
- Automatic folder watching with a polling fallback.
- Comprehensive test suite (31 test files).

### 📝 Notes

- Desktop-only. The minimum Obsidian version at this release was `1.5.0`; it was raised to `1.11.4` in 1.0.2.

### 🇯🇵 Inbox Curator v1.0.0 — 初回公開

Inbox Curator は、OpenAI / Gemini / Anthropic を使って Inbox フォルダのノートをレビュー・要約・自動仕分けする Obsidian プラグインです。

#### ✨ 主な特徴

- **AI ノートレビュー** — 要約・信頼性・タグ・推奨アクションを構造化データで取得します。
- **安全な自動仕分け** — Archive / Read Later / Task は自動実行できます。Delete Candidate は提案のみで、隔離フォルダへ移動するだけで削除はしません。
- **バッチ処理** — インメモリキューで並行数・レート制限・リトライを制御します。
- **多彩な入力** — URL 記事抽出、添付ファイル検出、画像レビュー（最大3枚・各1MB）、実験的な PDF テキスト抽出に対応します。

#### 📦 同梱機能

- コレクションレビュー（複数ノートの横断分析）
- 自動仕分けの Undo（`Undo last auto-sort run`）
- コンテキストバジェットのプリセット（small / standard / large / custom）
- 構造化オペレーションログ（JSONL）とローテーション式エラーログ（`.inbox-curator/logs/`）
- 英語・日本語 UI（i18n）
- 画像のインメモリ最適化（ソース画像は最大 10MB）
- プロンプトインジェクション検出（ブロック設定可）
- プロバイダーエラーの分類によるわかりやすいエラーメッセージ
- `SecretStorage` による API キー保管（利用不可時はセッション内メモリにフォールバック）
- `ai_review_source_hash` による重複排除
- フォルダ監視（ポーリングフォールバック付き）
- テスト一式（31 ファイル）

#### 📝 補足

- デスクトップ専用。本リリース時点の最低 Obsidian バージョンは `1.5.0` で、1.0.2 で `1.11.4` に引き上げられました。
